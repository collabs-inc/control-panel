# Terminals, CI/CD, balancer: implementation plan

**Spec:** `docs/superpowers/specs/2026-09-30-terminals-ci-balancer-design.md` (binding).
**Tech:** Go 1.27 stdlib + vanilla JS; `go test ./...` (race: `CC=gcc CGO_ENABLED=1 go test -race ./...`), `node --test lib_test.js`.

**Global constraints:**
- No git in this dir.
- Test instance :7788 `-insecure-no-access` with a scratchpad PIN only.
- Never send keys to the owner's real panes while testing: use the throwaway zellij session `cp-probe`.
- Ship with `./ensure-panel.sh restart`.
- The CSP forbids inline script and style.
- Every innerHTML interpolation goes through `esc()`.

**Ruling:** this plan is a task list with interfaces and tests rather than full code. The owner asked for autonomous iteration to completion, and the spec carries the design. Cost if wrong: less upfront detail per task.

## Tasks

1. **Hygiene.**
   - Actions need no PIN (the session is enough; still audited).
   - Remove `focus-pane` (and `hasPane`, `focusPane`, their tests, the modal PIN field).
   - `cleanEnv()` strips `ZELLIJ*`, `CLAUDE*`, `CLAUDECODE` and `AI_AGENT` for zellij execs.
   - Tests: an action without a PIN → 200; `focus-pane` → 404; `cleanEnv` output.
2. **Claude sessions** (`claude.go`): `readClaudeSessions(dir string, startOf func(int) (uint64, bool)) []claudeProc`, with fields `{PID, SessionID, Cwd, Name, Status, WaitingFor, Since}`. It drops dead or reused pids and clamps unknown statuses to "".
   - Tests: temp-dir fixtures.
3. **Transcripts** (`transcript.go`):
   - `transcripts.path(sessionID)` (glob + cache);
   - `readTail(path, max)`;
   - `parseChat(lines [][]byte) []ChatItem`;
   - `lastDoing(items)`;
   - `subagents(dir, now, parentAlive) []Subagent` (cached by size+mtime);
   - `readChatBefore(path, off)`.
   - Tests: fixture lines (user, meta, assistant text, tool_use/result pairing, thinking hidden, turn_duration note, huge line skipped); subagent final vs running vs stale.
4. **Zellij** (`zellij.go`):
   - `zj` struct with an injectable `run(ctx, args, env)`;
   - `listPanes(session)` → `[]zPane`;
   - `newSession`, `newTab`, `newPane`, `paste`, `sendKeys`, `dumpScreen`, `subscribe` (exec.Cmd);
   - `parsePrompt(screen string) *Prompt`.
   - Tests: a list-panes fixture, a prompt fixture from the real screen text, argv captured for each command.
5. **Terminals model** (`terminals.go`):
   - The sampler exposes pane roots (`paneInfo{root, tty, fgPid, fgState, fgCmd, cpu, rss, n}` by key) and `keyOf(pid)`.
   - `procStat` gains PGRP and TPGID.
   - `buildTerminals(sessions, panesBySession, paneInfo, claude, fallback, now) Terminals` with the pure `paneState(...)`.
   - Tests: table-driven states and counts; stable ordering.
6. **Server wiring:**
   - view `term`, list-panes cadence of 3 s, badges;
   - `/api/pane/stream` (chat/screen), `/api/pane/chat`, `/api/pane/input`, `/api/term/new`.
   - Tests: validation (bad session, dead session, oversize text, bad key, bad cwd, bad name), argv via the fake runner, audit entries.
7. **Web Terminals:**
   - nav rename;
   - the view (stable rows, subagent dropdown);
   - the drawer (Chat/Screen, composer, quick keys, permission banner);
   - the create form;
   - an ANSI SGR→HTML parser and a mini-markdown renderer in `lib.js`, with node tests.
8. **CI:**
   - `workerMeta(path)`, job↔worker matching, `ByWorkflow`, `Recent` completed only (200), `Runner.Meta`;
   - gh titles cache;
   - web: the live table, grouped job types, scrollable lists.
   - Tests: a worker-log fixture, matching, grouping.
9. **Balancer:**
   - `limits.go`: a rules store (0600 JSON), an enforcer with its own sampler, `applyRule(pids, rule)` with injectable syscalls, guards;
   - an action endpoint `POST /api/limit`;
   - web: the Limit panel and Limits card.
   - Tests: rule persistence, guards, which syscalls get applied (fake).
10. **E2E + ship:**
    - `cp-probe` with a real `claude` (haiku): status transitions, a permission prompt answered from the panel, chat content, screen view;
    - phone and desktop screenshots;
    - race suite;
    - `ensure-panel.sh restart`;
    - a final review subagent; fix Critical/Important.
