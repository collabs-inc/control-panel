Files: a file manager in the sidebar

A new Files section for browsing everything under your home folder and /tmp. You can open any document in the panel, edit text files, upload, rename, move and delete, and hand a file to an agent. The screens use the panel's real styles and icons. Data is made up.

Does: browse · preview · edit · upload · rename · move · delete · send to agent Reach: ~ and /tmp Secrets: treated like any file Renderers: in the browser (pdf.js, SheetJS, docx-preview, lazy-loaded) pptx, .doc, .ppt: download only Editor: text and code open editable (CodeMirror, lazy-loaded)

Rev 3: the left side is a tree. Click a folder to expand it in place, double-click to open it as a big view (D2). Files open in tabs, and two can sit side by side (D3). Long files get a minimap (D5). New ▸ Clone pulls a git repo onto the box (D9). ⌘K searches every file, hidden ones too (D10). Resources trades Storage and Disk usage for memory (R1).
Rev 2: Files runs edge to edge. The sidebar folds to icons and the page header goes, the list is narrower and drag-resizable, F hides the list so a file gets the whole width, and editing is a real editor (D5, D6, P7).
